2. GC Entry - Waybill Creation

Goods Consignment Note Generation

GC Entry Form Interface
Consignor/Consignee Selection • Multi-Article Table • Charges Summary

Form Sections:

Section Fields
Basic Info GC Date, Branch, Consignor, Consignee
Articles Type, Quantity, Weight, Rate (Multi-row)
Charges Freight, DD, Handling, Stationary

4. Trip Sheet Verification - Financial Audit

Audit & Finalization

Trip Verification & Audit Interface
Financial Summary • Profit/Loss Logic • Verify & Print Controls

Verification Process:

  1. Filter by branch and date range
  2. Review financial summary (Freight, Advance, Driver Pay)
  3. Check Profit/Loss calculation
  4. Verify and lock the record
  5. Print trip voucher (A4 format)

Access Control:

  • Branch Admin: Locked to their branch only
  • Superadmin: Can verify all branches
  • Auto-loads pending verifications on screen open
Print Output: Professional A4 voucher with company logo, all financial details, and signature fields

Income Heads Expense Heads

6. Receive GC Ack - Delivery Confirmation

Final Delivery Processing

Electronic Acknowledgment (Ack) Interface
GC Search • Status Timeline • Digital Acknowledgment Receipt

Screen Layout:

  • Left Panel: Quick search + Pending Ack list
  • Right Panel: Selected GC details card

GC Details Display:

  • Shipping route (From → To)
  • Consignor & Consignee names
  • Package overview (Articles, Total)
  • Current status badge

Confirmation Process:

  1. Search or select from pending list
  2. Review GC details
  3. Click "Confirm Acknowledgement"
  4. Status updates to DELIVERED
  5. Delivered branch recorded automatically
Database Update: Sets status=DELIVERED, deliver_status=DELIVERED, delivered_branch_id

7. Update Delivery - Real-time Status Updates

Shipment Tracking & Status Management

Update Delivery Interface
GC Status Update • Remark Tracking • Location History

Operational Features:

  • Status Transitions: Arrived at Destination → Out for Delivery → Delivered
  • Proof Component: Mandatory scan or upload of delivery proof (PDF/JPG) before status update is allowed
  • Exceptions Tracking: Mark GCs as RTO (Return to Origin) or Redirected
  • Remarks History: Capture reasons for delays or exceptions
  • Audit Trail: Every status change timestamped and user-stamped

Delivery Reports:

Report Type Analytical Value
Status Report Filter by branch, date range, and current delivery status
Exception Summary List of all RTO and Redirected GCs with remarks
Delivery Performance Time taken from Inward to Final Delivery
Business Value: Ensures end-to-end visibility of shipments even after reaching the destination branch.

10. Technical Architecture

Frontend (React.js)

  • Components: 87 page components, reusable UI elements
  • State Management: React Hooks (useState, useEffect)
  • Routing: Multi-tab interface with TabContext
  • Styling: Tailwind CSS for modern design
  • Icons: Lucide React library

Backend (Laravel)

  • Architecture: MVC pattern with RESTful API
  • Database: Eloquent ORM with 30+ tables
  • Validation: Request validation on all inputs
  • Security: Role-based access control
  • API Endpoints: 100+ endpoints for all operations

Database Design

  • Normalized to 3NF
  • Foreign key constraints for referential integrity
  • Soft deletes for data preservation
  • Indexes for performance optimization
  • Timestamps for audit trail

12. Complete Workflows

Workflow 1: GC Journey

  1. GC Entry: Create waybill at origin branch
  2. Trip Sheet Entry: Attach GC to vehicle dispatch
  3. Bulk Inward: Receive at destination branch
  4. Receive GC Ack: Mark as DELIVERED
  5. Payment: Record payment from consignor
  6. Reports: Generate consignor statement

Workflow 2: Trip Sheet Lifecycle

  1. Trip Sheet Entry: Create trip with GCs and advance
  2. Vehicle Dispatch: Driver departs
  3. Trip Sheet Ack: Acknowledge completion
  4. Trip Sheet Verification: Audit finances and verify
  5. Print Voucher: Generate A4 trip report
  6. Trip Sheet Payment: Settle driver balance

Workflow 3: Daily Cash Management

  1. Cash Book Entry: Record all income/expense
  2. Day Book Closure: Close day with balances
  3. Cash Book Report: Generate daily report
  4. Headwise Report: Analyze by account heads
  5. Balance Sheet: View financial position
